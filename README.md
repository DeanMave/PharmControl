# PharmControl
💊 PharmControl - это консольное приложение для управления аптекой 
🔷 Описание проекта
Данный проект разрабатывается как первый pet-проект. 
Цель – автоматизировать процесс продаж в аптеке:  
- Учет наличия лекарств на складе  
- Проведение продаж и списание препаратов  
- Начисление и списание бонусов для постоянных клиентов  
- Контроль сроков годности  
🚀 Текущий статус:
-Ведется разработка основных классов и бизнес-логики приложения
